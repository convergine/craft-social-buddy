# Social Buddy - Changelog

All notable changes to this project will be documented in this file.


## 1.1.0 - 2025-09-24

### Changed
- The automatic posting mechanism has been redesigned. The publication status is now stored in a custom entry field named socialBuddy
- Fixed initial social network connection/disconnection for CraftCMS 5.8.*
- Enhanced posting for LinkedIn, X (Twitter), and Pinterest.
- Improved error handling, logging and UI user notifications

## 1.0.2 - 2025-02-06
### Added
- Added Pinterest boards selection list on the post publishing page.

### Changed
- Changed Instagram image resize implementation to enforce 4:5 portrait aspect ratio
